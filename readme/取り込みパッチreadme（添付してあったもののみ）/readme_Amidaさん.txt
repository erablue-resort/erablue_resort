イベント性交記録関数追加パッチ（2026年10月2日）

■内容
口上個別イベント向けに、初回・相手別記録、喪失状態・履歴、経験差分の処理を共通化しました。
作者向け関数名は「イベント性交記録」です。

■導入
ゲームを終了し、上書き先ファイルをバックアップしてください。
このZIP内のERBフォルダとreadmeフォルダを、ゲームのERBとreadmeがある階層へ配置してください。
変更した既存ERBは3ファイル、新規ERBは1ファイルです。

■ゲーム用ファイル
ERB/TRACHECK.ERB
ERB/EVENTCOMEND.ERB
ERB/汎用関数/COMMON2.ERB
ERB/シナリオ/イベント状態記録共通処理.ERB

■変更内容
TRACHECKの4種類の初回登録・喪失準備を共通関数へ置換しました。
EVENTCOMENDの4種類の素質変更・履歴を共通関数へ置換しました。
COMMON2のうふふ開始時の双方の初回・相手別記録を共通関数へ置換しました。
手段3の履歴に前回の道具名が残る不具合を修正しました。
引数、非処女・再生処女、再鑑賞、経験加算の扱いは使用方法に記載しています。
