舞踏会『特殊営業』追加パック
----------------------------------------

■ 追加内容
　楊菲菲（2037）の特殊営業に、新シチュエーション「中華青楼（花月楼）」を追加しました。

■ 上書きされるファイル
　ERB\シナリオ\突発イベント\花月楼\花月楼.ERB
　ERB\シナリオ\突発イベント\突発イベント_『舞踏会』への招待\特殊営業.ERB
　ERB\シナリオ\突発イベント\突発イベント_『舞踏会』への招待\突発イベント_『舞踏会』への招待.ERB

■ 画像
　resources\2037フェイフェイ\ に、イベントで使う画像と連番アニメを入れてください。

■ 備考
　突発イベント_『舞踏会』への招待.ERB は、テスト用の記述を消して元の内容に戻しました。

　動作確認：Ver0.111 / Emuera.NET 1.824+v24+EMv18+EEv55



【これは何か】
　『舞踏会』への招待で発生する特殊営業イベントの拡張パックです。

【導入方法】
　ゲームのルートフォルダに上書きしてください。

【追加内容】
　・事後の分岐が 3 種類に増えます
　・それに合わせた写真を同梱しています

【画像について】
　resources\1484みく\ と resources\1667蘭子\ に画像を追加します。
　既に同名ファイルがある場合は上書きされます。

【技術メモ】
　CFLAG の 410 番を使用します。他の MOD と衝突する場合は注意してください。
（バリ主追記：CFLAGからユーザー定義変数に移しました、衝突の危険はありません）
