パッシブとファズの表示処理は `固有アビリティ_ハル子.ERB` 内にあります。

加入イベント「空から落ちてきた女」は、人食い鳥の島クリア後に発生します。
Lv4の人食い鳥5体との戦闘を2ウェーブ行い、全勝後に招待を解放し、空き枠に応じて予約します。
CSVの `招待不可フラグ` は3なので、ZPショップからの解放も可能です。
イベントの台詞と地の文は、現在配置されている調整済みERBを収録しています。
