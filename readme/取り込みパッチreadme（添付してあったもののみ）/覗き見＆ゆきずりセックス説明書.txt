■各機能の説明

・覗き見システム
　対象を覗き見て、「おっ！やってんねえ！＾＾」を愉しむシステムです。
　解放には「魔法知識」がLv1以上で発生するサブクエスト「使い魔の創造」のクリアが必要です。
　いろいろ機能を追加したいところですね。
　
　
・性癖：ゆきずりセックス
　性欲がたまるとその辺の観光客(モブ)を誘惑して物陰や自室でヤり始めます。
　同じ場所で覗く、物陰に隠れる、使い魔による覗き見でじっくりと見れます。
　女性から男性、ふたなりまで対応できるようになってます。
　
　独自の立ち絵変更処理を持っており、
　　短冊_XXX_差分_覗きセックス
　　短冊_XXX_差分_覗きＡセックス
　　短冊_XXX_差分_覗き奉仕
　　短冊_XXX_差分_覗きバレセックス
　　短冊_XXX_差分_覗きバレＡセックス
　　短冊_XXX_差分_覗きバレ奉仕
　のファイルがあればそれが表示され……るはずでした。
　改修中の為、いったん機能を停止しております。

●ゆきずりセックス＆覗き見　～v2.00アップデートのお知らせ～
・ゆきずりセックスがキャラ同士うふふみたいな感じになりました。
　ゆきずり成立時にNPCを生成し、NPCとうふふし始めます。
　なお、以前のテキストは導入や射精時などに流用させていただいています。

・特定条件下で自室に連れ込み、長めにゆきずりするようになりました。

・ゆきずりセックス（攻め）と統合しました。
　前バージョンでのゆきずりセックス（攻め）の経験とレベルはゆきずりセックスと比較し、高い方が新ゆきずりセックスの経験とレベルになります。

・男性・ふたなりにも対応しました。
　ヘテロだけではなく、条件によってはレズ・ホモ・ふたによる逆アナルにも対応してます。

・使い魔を通じて遠くからゆきずりを眺めることができるようになりました。

・使い魔が監視中のキャラがゆきずりし始めると逐一チクるようになりました。

・使い魔の管理が起床前メニューからできるようになりました。

・機能修正の為、ゆきずり専用立ち絵を表示する機能をいったん止めています。



●ゆきずり以外の既存仕様の変更
・「覗く」コマンドが常時表示コマンドとなりました。
　既存の覗き場所は従来通りの動きを行い、それ以外の場所は物陰を覗く処理となりました。

・こちらが隠密状態ではない場合、隠密状態のキャラクターが同室者などから表示されなくなり、対象に取れなくなりました。
　隠れてナニをしているかは「覗く」コマンドで確認しましょう。

・こちらが隠密時、隠密状態ではないキャラクターが同室者一覧に表示されなくなり、隠密状態のキャラクターが表示されるようになりました。
　ようするに、同じ状態のキャラクターしか見れないようになっています。
