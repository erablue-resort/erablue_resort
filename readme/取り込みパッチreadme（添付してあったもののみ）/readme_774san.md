## ライセンスについて
許可する項目を"○"に、許可しない項目を"×"に変更してください。
| № | 許可 | ライセンス内容 |
| :---: | :---: | --- |
| 01 | ○ | 処理上のバグ修正 |
| 02 | ○ | 新規機能追加による内容改変 |
| 03 | ○ | バランス調整による内容改変 |
| 04 | ○ | 口上の誤字・脱字の修正 |
| 05 | ○ | 口上の新規追加・加筆 |
| 06 | ○ | 既存口上の改変 |
| 07 | ○ | 改変した口上の自由な再配布  |
| 08 | ○ | 口上内容の転載（erablue_resort内部に限る） |
| 09 | ○ | erablue_resort本体への収録 |
