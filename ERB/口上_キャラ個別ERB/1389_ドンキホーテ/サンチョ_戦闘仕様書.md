# サンチョのアビリティと奥義の仕様書

更新日：2026-10-11
対象：ドンキホーテ（キャラ番号1389）のサンチョスタイル
状態：本会話で決めた設計仕様。ゲームへの実装とテストプレイは未実施。

## 戦闘の方針

硬血を使ってHPとMPを大きく払い、攻撃による回収で戦い続ける。
出血から血餐を増やす前段階は設けず、独自の硬血だけで資源を管理する。
アビリティは硬血が0でも発動できる。
硬血不足だけを理由に技を使用不可にしない。
MP不足、カウンター効果中の再使用禁止など、ほかの発動条件は別に適用する。

技の攻撃倍率は、既存キャラの同種の技と同程度にする。
当初の「他キャラより少し高め」という方針は採用しない。
硬血による攻撃力上昇で、高い火力を得る設計にする。
具体的な攻撃倍率と、消費硬血に応じた技の威力補正は未定。

序盤に硬血を増やし、15以上を維持できるとしぶとくなる戦い方を想定している。
これは設計上の見立てであり、実際の生存力はテストプレイで確認する。
回収不足を感じた場合は、まずクリティカル率や連撃率などのバフ調整を検討する。

## パッシブ「硬血」

### 初期値と上限

| 項目 | 数値 |
|---|---:|
| 戦闘開始時の硬血 | 5 |
| 硬血の所持上限 | 30 |
| 能力上昇に使う硬血の範囲 | 0～20 |
| 最大HP | 通常の75％ |

硬血21～30は消費用の余剰分として持てるが、能力は硬血20の値で止まる。
戦闘開始時の硬血5には、獲得時のHP回復とMP回復を発生させない。

### 硬血による能力上昇

所持硬血を H とし、能力計算用の値を h = min(H, 20) とする。
0～20の間は直線的に上昇する。
以下の率は硬血パッシブによる設定値であり、装備やほかのバフとの最終的な合成方法は実装時に確認する。

| 能力 | 硬血0 | 硬血20以上 | 計算式 |
|---|---:|---:|---|
| 攻撃力アップ | ＋10％ | ＋90％ | 10＋4×h（％） |
| DA率 | 30％ | 90％ | 30＋3×h（％） |
| TA率 | 20％ | 75％ | 20＋2.75×h（％） |
| クリティカル率 | 40％ | 100％ | 40＋3×h（％） |

攻撃力アップは、旧案の＋0～60％から＋10～90％へ変更済み。

| 硬血 | 攻撃力アップ | DA率 | TA率 | クリティカル率 |
|---:|---:|---:|---:|---:|
| 0 | ＋10％ | 30％ | 20％ | 40％ |
| 5 | ＋30％ | 45％ | 33.75％ | 55％ |
| 10 | ＋50％ | 60％ | 47.5％ | 70％ |
| 15 | ＋70％ | 75％ | 61.25％ | 85％ |
| 20～30 | ＋90％ | 90％ | 75％ | 100％ |

小数値の丸め方は未定。
クリティカルは既存の有利属性時限定の判定を維持する。
必中は命中を保証する効果であり、クリティカルの保証にはしない。

### 硬血の獲得と回復

次の各条件を満たすたびに、硬血5を獲得する。
戦闘開始時を除く各獲得処理には、最大HPの15％のHP回復と、最大MPの10％のMP回復が付く。
HP回復の基準は、パッシブで75％に低下した後の最大HPとする。

| 獲得条件 | 回数の数え方 |
|---|---|
| 5ターン経過ごと | 5ターンごとに1回 |
| 自身の攻撃によるクリティカル | クリティカルが発生した命中ごとに1回 |
| 自身の通常攻撃によるDAまたはTA | DAまたはTAが発生したことに対して1回 |
| 自身の攻撃による敵の撃破 | 撃破した敵ごとに1回 |

複数の条件が重なった場合、それぞれの回収をすべて加算する。
連撃による回収はDAとTAのみを指す。
固定の3回攻撃、6回攻撃、奥義の4回攻撃は、それ自体ではDAやTAとして数えない。

硬血の所持数が30に達していても、獲得条件を満たした回数ぶんのHP回復とMP回復は発生する。
回復量は硬血1個ごとではなく、硬血5を獲得する処理1回ごとの値とする。
HPとMPは、それぞれの最大値を超えない。

### 回収回数の例

| 攻撃結果 | 回収回数 | 硬血の獲得量（上限適用前） | HP回復量の合計 | MP回復量の合計 |
|---|---:|---:|---:|---:|
| 血の歓喜でクリティカル3回 | 3 | 15 | 最大HPの45％ | 最大MPの30％ |
| TAの3発すべてがクリティカル | 4（クリティカル3＋TA1） | 20 | 最大HPの60％ | 最大MPの40％ |
| 硬血2式で6体にクリティカルし、6体とも撃破 | 12（クリティカル6＋撃破6） | 60 | 最大HPの180％ | 最大MPの120％ |
| 奥義でクリティカル4回、撃破なし | 4 | 20 | 最大HPの60％ | 最大MPの40％ |

表の回復量は各回復を合計した理論値。
実際の増加量は、その時点のHP不足量とMP不足量までになる。
奥義固有のHP回復は、この表のパッシブ回復とは別に発生する。

## HP消費とMP消費

### 実際の消費硬血数

血の歓喜、硬血11式、硬血2式、奥義では、発動前の所持硬血と各技の消費上限の小さい方を消費する。
上限数に足りなくても発動でき、所持分だけを消費する。
硬血0なら消費硬血数も0とする。

以下では、実際に消費する硬血数を S とする。

### HP消費

消費HP = 最大HP × S × 5％

このHP消費でHPは0にならず、最低1残る。
支払額が現在HP以上になる場合は、HP1までを支払う。
最大HPの基準は、パッシブで75％に低下した後の値とする。
硬血0では、この式によるHP消費は0になる。

### MP消費

消費MP = 各技の固定値 ＋ 最大MP ×（S × 各技の変動率）％

固定値と、消費硬血1あたりの最大MPに対する変動率は、アビリティと奥義ごとに個別設定する。
全技に「固定値30、変動率4％」を一律適用する旧案は撤回する。
技ごとの具体的な固定値と変動率は未定。

最大MPが増えても、割合部分によって消費量が増える設計を維持する。
最大MPが1,000を超えるような高レベルでも、硬血を消費した技で十分なMP出費が生じるよう個別に調整する。
硬血0では変動部分が0になり、その技の固定値だけを支払う。
消費硬血数と消費MPは、攻撃前に確定する。
攻撃後の回収で、その技の消費額を変えない。
MP不足時は発動できない。

| 技 | MP消費の固定値 | 消費硬血1あたりの変動率 |
|---|---|---|
| 血の歓喜 | 未定 | 未定 |
| 硬血11式 | 未定 | 未定 |
| 亜流硬血15式 | 未定 | 未定 |
| 硬血2式 | 未定 | 未定 |
| 奥義「亜流2式」 | 未定 | 未定 |

HP消費は、引き続き全技共通で消費硬血1あたり最大HPの5％とする。

| 技 | 消費硬血の上限 | 上限まで消費した場合のHP消費 |
|---|---:|---:|
| 血の歓喜 | 5 | 最大HPの25％ |
| 硬血11式 | 7 | 最大HPの35％ |
| 硬血2式 | 8 | 最大HPの40％ |
| 奥義「亜流2式」 | 15 | 最大HPの75％ |

亜流硬血15式は、発動時に消費する硬血数が未定のため、発動時コストを確定しない。
各反撃で硬血1を消費することは確定しているが、反撃時にもHPやMPを追加で支払うかは未定。
割合計算の端数処理は実装時に確定する。

## 消費と回収の処理順

1. 発動条件を確認し、その技で実際に消費する硬血数を確定する。
2. 硬血、HP、MPを支払う。
3. 攻撃前のバフを付与し、攻撃と攻撃後の効果を処理する。
4. 攻撃中に発生したクリティカル、DAまたはTA、撃破の回数を記録する。
5. 技の処理がすべて終わってから、記録した回数ぶん硬血を獲得し、獲得に伴うHP回復とMP回復を行う。

攻撃中は硬血の獲得と、その獲得に伴う回復を行わない。
同じ技の途中で硬血を獲得して、後続の攻撃や消費に使える状態を作らない。
奥義固有のHP回復は攻撃後の効果として扱い、硬血獲得時の回復と区別する。

既存の戦闘共通処理は、アビリティ効果の呼び出し後にMPを引く構造になっている。
本仕様の「先に支払い、最後に回収」を実装する際は、回復が満タンで切り捨てられてからMPを引く順序や、MPの二重消費を避ける必要がある。
これは実装上の確認事項であり、今回ゲーム処理を変更したことを意味しない。

## アビリティと奥義

### 1アビ「血の歓喜」

| 項目 | 内容 |
|---|---|
| 対象 | 敵単体 |
| 攻撃 | 3回攻撃 |
| 硬血消費 | 最大5 |
| 攻撃前の効果 | 自身の攻撃力と防御力を、それぞれ20％アップ |
| バフ枠と持続 | どちらもA枠、5ターン |
| 専用CT | なし |

攻撃力アップと防御力アップは、3回攻撃の前に付与する。
クリティカルは各命中で判定し、その回数ぶん回収を記録する。

### 2アビ「硬血11式」

| 項目 | 内容 |
|---|---|
| 対象 | 敵単体 |
| 攻撃 | 防御無視攻撃を1回 |
| 硬血消費 | 最大7 |
| 攻撃後の効果 | 確率で防御力ダウンを付与し、敵のバフを削除 |
| 防御力ダウン | 30％、独自枠、5ターン |
| 付与確率 | 消費した硬血数×20％。100％以上は確定付与 |
| 専用CT | なし |

硬血1なら20％、硬血4なら80％、硬血5以上なら確定付与になる。
バフ削除は、防御力ダウンの成否に関係なく行う。
削除するバフの個数、消去不可効果の扱いは未定。

### 3アビ「亜流硬血15式」

| 項目 | 内容 |
|---|---|
| 対象 | 自身 |
| 効果 | カウンターを付与 |
| 持続 | 4ターン |
| 反撃回数 | 無制限 |
| 硬血消費 | 反撃が発動するたびに1 |
| 反撃時の累積強化 | クリティカル率、DA率、TA率を、それぞれ10ポイントアップ |
| 累積強化の持続 | カウンターが解除されたら、累積分もすべて解除 |
| 専用CT | 4ターン |
| 重ねがけ | カウンター効果中は再使用不可 |

累積強化の上限は未定。
カウンターが終了するときは、硬血パッシブやほかの技のバフを消さず、このカウンターに由来する累積分を解除する。
発動時の硬血消費数、硬血0での反撃の継続と累積強化、反撃ごとの消費と回収の区切りは未定。

### 4アビ「硬血2式」

| 項目 | 内容 |
|---|---|
| 対象 | 敵全体からランダムに選択 |
| 攻撃 | ランダム6回攻撃 |
| 硬血消費 | 最大8 |
| 攻撃前の効果 | 自身のクリティカル率アップ |
| 攻撃後の効果 | 自身に最大HPの10％のバリアを付与 |
| 専用CT | なし |

「敵全体に各6回」ではなく、敵全体を候補とする合計6回のランダム攻撃とする。
クリティカル率アップの量、枠、持続時間と、バリアの持続時間や再使用時の扱いは未定。

### 奥義「亜流2式」

| 項目 | 内容 |
|---|---|
| 対象 | 敵単体 |
| 攻撃 | 必中の4回攻撃 |
| 硬血消費 | 最大15 |
| 攻撃前の効果 | 自身のクリティカルダメージ率を強化 |
| 強化後の倍率 | 基本の1.5倍から2倍へ（クリティカルダメージ率に＋50ポイント） |
| バフの持続 | 3ターン |
| 攻撃後の効果 | 与えたダメージに応じて自身のHPを回復 |
| 固有回復の上限 | 最大HPの50％ |
| 専用CT | なし |

クリティカル威力アップは、奥義の4回攻撃の前に付与し、攻撃後も残る。
「クリティカル威力をさらに2倍する」効果にはしない。
バフ枠と、ほかのクリティカル威力バフとの合成は未定。

固有のHP回復は、4回攻撃で実際に与えたダメージの合計を参照する。
与ダメージの何％を回復に換算するかは未定だが、固有回復だけの上限は最大HPの50％とする。
クリティカルや撃破によるパッシブ回復を、この50％の上限に含めない。
奥義名の正式表記と通常の奥義発動条件の詳細は、実装時に確認する。

## スタイルとの関係

戦闘仕様の前提として、サンチョはドンキホーテのスタイルとして扱う。
恋慕陥落後にキャライベントが発生し、戦闘でサンチョを倒すと永久解禁される。
一度解禁した後は自由に切り替えられる。

ドンキホーテとサンチョは、それぞれの固有アビリティと奥義を持つ。
サンチョの得意武器は槍と拳とする。
サンチョCSVは将来削除される想定のため、必要なスタイル設定はドンキホーテ側に保持する方針。
プレイで変動する数値、性癖、学習レベルなどは、スタイルを切り替えても共有する。
人格や外見に関する切り替え項目の一覧は、本仕様書の対象外とする。

## 実装時に確認する例

- 硬血0でも各アビリティを発動でき、HP消費が0になること。
- 所持硬血が技の上限より少ないとき、所持分だけでHP消費とMP消費を計算すること。
- HP消費が現在HP以上でも、HP1が残ること。
- 各技で設定した固定値と変動率を使ってMP消費を計算し、硬血0ではその技の固定値だけを支払うこと。
- 攻撃の途中では硬血が増えず、すべての処理終了後に回収すること。
- 硬血2式のクリティカル6回と撃破6体で、回復が12回発生すること。
- TAの3回クリティカルで、クリティカル3回とTA1回の合計4回を回収すること。
- 硬血が30でも、獲得条件に応じたHP回復とMP回復を行うこと。
- 5ターンごとの硬血獲得では回復し、戦闘開始時の獲得では回復しないこと。
- カウンター効果中は亜流硬血15式を再使用できず、解除時に専用の累積強化だけを消すこと。
- 奥義のクリティカル威力バフが1発目から有効になり、固有回復の50％上限がパッシブ回復を制限しないこと。
