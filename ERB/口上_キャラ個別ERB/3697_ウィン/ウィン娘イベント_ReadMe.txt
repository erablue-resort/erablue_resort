================================================================================
  [蒼翠の風霊使い]ウィン（ID:3697）育児系キャライベント
  ReadMe
================================================================================

■ 概要
  ウィンとの間に生まれた娘をめぐるキャライベント群です。
  チェーン式5本 ＋ 妄想1本 ＋ 突発ランダム6本 ＋ 娘独白1本、全14イベント。

■ 導入方法
  口上_キャラ個別ERB/3697_ウィン/ に4ファイルを配置してください。

■ ファイル一覧（計2638行）
  キャライベント_ウィン、風と娘の物語.ERB  （1046行）チェーン5本
  キャライベント_ウィン、もしもの夜風.ERB  （ 295行）妄想イベント1本
  キャライベント_ウィン、風と娘の日々.ERB  （ 732行）突発ランダム6本
  キャライベント_ウィン、翠色の娘の一日.ERB（ 565行）娘独白ランダム

■ CFLAG使用一覧
  CFLAG:200  育児チェーン進行（0=未開始, 1=CH01済, 2=CH02済, 3=CH03済, 4=CH04済, 5=CH05済）
  CFLAG:201  EXイベントクールダウン（チェック毎に-1、0で発生可能）
  CFLAG:204  妄想イベント完了フラグ（0=未完了, 1=完了）

================================================================================
■ イベントチェーン（発生順序）
================================================================================

  CH01 → CH02 → もしもの夜風 → CH03 → CH04 → CH05 → EX/独白

  ※CH01～CH05は順番に1本ずつ発生します。
  ※「もしもの夜風」はCH02とCH03の間に挟まる必須イベントです。

--------------------------------------------------------------------------------
  CH01「風の揺り籠」（出産～娘の急成長）
--------------------------------------------------------------------------------
  発生条件：
    ・恋慕状態であること
    ・MASTERの子供を妊娠した回数が1回以上（CFLAG:508）
  完了時：CFLAG:200 = 1
  内容：出産→eraの力で娘が急成長→風霊使いの血を引く娘の紹介

--------------------------------------------------------------------------------
  CH02「風が運ぶ声」（娘の性的目覚め）
--------------------------------------------------------------------------------
  発生条件：
    ・恋慕状態であること
    ・CH01完了（CFLAG:200 == 1）
  完了時：CFLAG:200 = 2
  内容：風の精霊が両親の営みの声を娘に運ぶ→初オナニー→えっちな本
        →父への恋心の自覚→決意

--------------------------------------------------------------------------------
  CH02.5「もしもの夜風」（娘の妄想・夢オチ）
  ※別ファイル：キャライベント_ウィン、もしもの夜風.ERB
--------------------------------------------------------------------------------
  発生条件：
    ・恋慕状態であること
    ・CH02完了（CFLAG:200 == 2）
    ・未完了（CFLAG:204 == 0）
  完了時：CFLAG:204 = 1
  内容：娘の独白形式。父を逆レイプする妄想→カウントダウン射精
        →実は全部妄想でした（夢オチ）

--------------------------------------------------------------------------------
  CH03「嵐の夜に」（一線を越える）
--------------------------------------------------------------------------------
  発生条件：
    ・恋慕状態であること
    ・CH02完了（CFLAG:200 == 2）
    ・もしもの夜風完了（CFLAG:204 == 1）
  完了時：CFLAG:200 = 3
  内容：嵐の夜に娘が忍び込む→選択肢あり
    [0] 娘の想いを受け入れる → 初体験シーン（長尺4ページ）→ウィンが廊下で聞いている
    [1] 親子ではできない → 拒絶するが娘は諦めない→進行は同じ（将来受け入れる含み）

--------------------------------------------------------------------------------
  CH04「二つの風」（母と娘の会話）
--------------------------------------------------------------------------------
  発生条件：
    ・恋慕状態であること
    ・CH03完了（CFLAG:200 == 3）
  完了時：CFLAG:200 = 4
  内容：深夜の中庭でウィンと娘が向かい合う。娘が告白、ウィンが受け入れる。
        「風は誰かのものじゃない。みんなのところに吹く」

--------------------------------------------------------------------------------
  CH05「風霊使いの花嫁修業」（親子丼）
--------------------------------------------------------------------------------
  発生条件：
    ・恋慕状態であること
    ・CH04完了（CFLAG:200 == 4）
  完了時：CFLAG:200 = 5、CFLAG:201にクールダウン設定（1～4日）
  内容：ウィンが娘にえっちを教える提案→ダブルフェラ→ウィン騎乗位（実演）
        →娘騎乗位（ウィンの指導付き）→三人で事後

================================================================================
■ 突発ランダムイベント（CH05完了後）
  ファイル：キャライベント_ウィン、風と娘の日々.ERB
================================================================================

  発生条件：
    ・恋慕状態であること
    ・CH05完了（CFLAG:200 == 5）
    ・クールダウン完了（CFLAG:201 == 0）
  発生方式：
    ・完了フラグなし（繰り返し発生）
    ・通常時はEX01～04の4本からランダム、淫乱時はEX05～06を加えた6本から選出
    ・発生後、1～4日のクールダウンが入る（CFLAG:201）

  EX01「そよ風のお目覚め」（娘と二人きり・朝フェラ→騎乗位）
  EX02「木漏れ日の秘密」（娘と二人きり・屋外、後背位→木の根元で事後）
  EX03「風使いの手ほどき」（3P・ウィン主導、騎乗位レッスン→顔面騎乗）
  EX04「翠色のおねだり」（3P・娘主導、ダブル舐め→ウィン正常位→娘騎乗位）
  EX05「止まらない風」（淫乱限定・娘の夜這い連続絶頂、母と同じ体質に）
  EX06「血は争えない」（淫乱限定・前夜の残り香を娘が舐め取る→騎乗位）

================================================================================
■ 娘独白イベント（CH05完了後）
  ファイル：キャライベント_ウィン、翠色の娘の一日.ERB
================================================================================

  発生条件：
    ・恋慕状態であること
    ・CH05完了（CFLAG:200 == 5）
  発生方式：
    ・完了フラグなし（繰り返し発生）
    ・7パート×各4パターン＝28シーンからランダム構成
    ・娘の一人称視点による一日の描写

  パート構成：
    朝（起床）→ 午前（登校）→ 昼（クラスの男の子）→
    夕方（下校）→ 夕方（お風呂）→ 夜（営み）→ 深夜（おやすみ）
