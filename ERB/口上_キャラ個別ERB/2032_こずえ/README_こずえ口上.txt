■ 概要
──────────────────────────────
遊佐こずえ（アイドルマスター シンデレラガールズ）の
erablue_resort用キャラクター口上です。

「ここじゃないところからきた」不思議な妖精の子。
全ひらがなの幼い口調、小さな体、翠の瞳。
えっちなことを何も知らないところから、少しずつ覚えていきます。

淫乱覚醒・恋慕・ゆきずり・出産・おやこえっちまで、
こずえの成長と堕落を丸ごと体験できる口上セットです。


■ 導入方法
──────────────────────────────
1. 7-Zipで解凍してください
   （Windows標準エクスプローラーでは日本語ファイル名が文字化けします）

2. 解凍した「2032_こずえ」フォルダをそのまま
   erablue_resort/ERB/口上/ の下にコピーしてください

   erablue_resort/
   └ ERB/
     └ 口上/
       └ 2032_こずえ/    ← ここにコピー

         ├ 口上_こずえ_コマンド実行時_日常.ERB
         ├ 口上_こずえ_イベント発生時.ERB
         ├ ...（全19ファイル）

3. ゲームを起動してください。特別な設定は不要です。
   招待不可キャラのため、ゲーム開始時に自動で登場します。

■ キャライベント
──────────────────────────────
ゲーム中「キャライベント」コマンドから選択して発生します。
フラグ管理付きで、一度クリアしたイベントも再視聴できます。

① かんさつにっき
   こずえの体をじっくり観察する。えっちの入口。

② せーきょーいく
   こずえにえっちなことを教える。性知識の目覚め。

③ はつじょーき
   こずえの体が反応し始める。発情の自覚。

④ おせきはん
   こずえの初潮。体の変化を受け止める。

⑤ おちんちんがり
   興味が暴走。おちんちんへの執着が芽生える。

⑥ こずえのいんらんかくせい
   淫乱覚醒の選択イベント。許可すると淫乱TALENT取得。
   （プレイヤーの選択制・中止可能）

⑦ おやこえっち（別ファイル）
   条件: 淫乱 + 出産済み + 娘がキャラ化済み
   母娘3Pの6幕構成。英才教育から交互挿入まで。


■ エンディング（4本）
──────────────────────────────
ゲームのエンディング選択時に条件を満たすと出現します。

ED1『ゆきずり中毒淫乱ぷにあな天使』
  条件: 淫乱 + ゆきずり中毒
  概要: 誰のおちんちんでもOKになった妖精の子。
        施設中の男に可愛がられる乱交エンド。

ED2『ようせいのこのやくそく』
  条件: 恋慕 + 非淫乱
  概要: おーなーさんだけを好きになった妖精の子。
        告白→初夜の純愛エンド。体格差描写あり。

ED3『おーなーさんせんようぷにあな天使』
  条件: 淫乱 + 恋慕 + 非ゆきずり中毒
  概要: えっちなことは大好き、でもおーなーさんだけ。
        朝昼夜3連射の専属エンド。濃厚。

ED4『いんらんおやこぷにあな天使』
  条件: 淫乱 + おやこえっちイベント完了
  概要: 母娘で毎日おやこどん。爛れた家族の日常エンド。
        おやこえっちイベントの後日譚。


■ こずえの成長ルート
──────────────────────────────
こずえは複数のルートに分岐します。

  【共通】
  かんさつにっき → せーきょーいく → はつじょーき
  → おせきはん → おちんちんがり

  【恋慕ルート】 → ED2 ようせいのこのやくそく
  淫乱覚醒を「しない」＋恋慕TALENT取得

  【淫乱ルート】
  いんらんかくせい → ゆきずり愛好 → ゆきずり中毒
                                     → ED1 ゆきずり中毒
                  → 恋慕TALENT取得
                     → ED3 おーなーさんせんよう
                  → 出産 → おやこえっち
                     → ED4 いんらんおやこ


■ 口上の特徴
──────────────────────────────
・全ひらがな口調
  台詞はすべてひらがな。漢字は使いません。
  地の文は通常の日本語で書かれています。

・体格差描写
  130cm/28kgの小さな体と大人の体格差を、
  数値ではなく体感で描写しています。
  「片腕で抱え込める」「影にすっぽり消える」
  「突くたびに体が浮く」「下腹がぼこりと膨らむ」等。

・通常/恋慕/淫乱 3段階分岐
  主要な口上は通常・恋慕・淫乱の3分岐で書かれています。
  通常: 何もわからない無垢な反応
  恋慕: 「……」や言い淀みで色気を出す（ハートなし）
  淫乱: ドスケベ全開、ハートマーク付き

・妊娠分岐
  V挿入・射精・絶頂・モード・夜這い等の主要口上に
  妊娠中の差分が入っています。

・サブコマンド対応（19関数）
  キス派生、乳首吸い派生、手コキ派生、フェラ派生、
  V挿入派生、A挿入派生に対応しています。

・道具対応
  バイブ・アナルバイブ等の道具コマンドに対応。

・オートコマンド（17関数）
  V挿入、A挿入、キス、フェラ、いちゃつく、
  ボディタッチ等のAI自動行動に対応。
