;●コマンド番号について：
;　コマンドはそれぞれ固有の番号を持つ。
;　たとえば愛撫の場合は「0」、クンニの場合は「1」、スパンキングの場合は「22」といった数値を持つ。
;　（これは数字型）
;　派生コマンドについては「XX_Y」というかたちで入る。
;　例えば……
;　　キス（コマンド番号20）の派生、ディープキス（派生１）は「20_1」
;　　フェラチオ（81）の派生バキュームフェラ（派生３）は「81_3」
;　……といった形で入る。
;　（これは文字列型。アンダースコア入ってるしね）
;　このあたり詳しくは後述。
;　/
;　このコマンド番号が、変数「コマンド初回フラグ:対象キャラ:0」に記録されていない場合、「このコマンドは初めて実行された」と分かる。
;　（コマンド実行後、初めてのコマンド番号のものは記録される）
;　この関数の「対象コマンド」の指定は、コマンド初回フラグに保存される文字列を指定する。
;　/
;　コマンド番号は下記ふたつの変数のどちらかから持ってくる。
;　１、SELECTCOM
;　　シンプルに「今選んでるコマンドの番号」を格納するための変数。
;　　愛撫を選べば「0」、スパンキングなら「22」、フェラチオなら「81」。
;　　ただしフェラチオ派生３、バキュームフェラ「81_3」などの場合、こちらには「-1」が入る。
;　　（つまりこっちがマイナス１だったら、「RSTR:SELECTCOM_S受け渡し」のほうになんかが入っている）
;　２、変数「RSTR:SELECTCOM_S受け渡し」
;　　派生コマンドはこちらで持つ。
;　　SELECTCOMにマイナス１が入っている場合＝派生コマンドが発生した場合、こちらを見る。
;　……このどちらかに、実行したコマンド番号が入っている。
;--------------------------------------------------
;--------------------------------------------------
;●コマンド番号/モード名称のパターンについて：
;　上述の通り、コマンドは番号（番号名称）を持つ。
;　そのパターンは、下記のごときである。
;　/
;　・通常コマンド（派生でない日常系・うふふ系コマンド）
;　　愛撫「0」、スパンキング「22」、フェラチオ「81」、会話「300」など。
;　　シチュエーションで名称が変更されるコマンド名もあるが、これは内部的には同じコマンド番号を持つ。
;　　例えば、単体対象の「愛撫」、複数モードの「同時に愛撫」は、どちらも愛撫のコマンド番号「0」を持つ。
;　　（理想を言えばこれも分けたいが……まあ仕方あるまい）
;　・派生コマンド
;　　キス（コマンド番号20）の派生、ディープキス（派生１）は「20_1」、フェラチオ（コマンド番号81）の派生３、バキュームフェラ「81_3」など。
;　　「派生元コマンド＋アンダーバー＋派生番号」という形で作られる。
;　・マッサージモード
;　　「MASSAGE_7」のように「MASSAGE_」が、コマンド番号の前に入る。
;　・むりやりうふふモード
;　　「RAPE_5」のように「RAPE_」が、コマンド番号の前に入る。
;　・場所固有コマンド
;　　「場所コマンド番号_マップ種別_現在位置」、例として「380_0_304」といった形になる。
;　　バーベキューエリアの固有コマンド「バーベキューをする」なら、
;　　「場所固有コマンド１（380）_リゾートエリア（0）_バーベキューエリア位置番号（304）」という番号になる。
;　・キャラ固有コマンド
;　　「固有コマンド番号_キャラ番号」、例として「370_1042」というカタチになる。
;　　例はフェルン（キャラ番号1042）の固有コマンド１（COM370）「『性教育』を始める」コマンド。
;　・お祭りコマンド
;　　「祭りコマンド番号_FESTIVAL_祭り名称」、例として「385_FESTIVAL_ハロウィンパーティ」というカタチになる。
;　・性処理業務/パパ活
;　　「WORKING_業務名」、例として「WORKING_セックス処理」という形になる。
;　　セックス処理や手コキ処理などの詳細を確認できる。
;　　なお、「コマンド：性処理業務」自体の経験は、コマンド番号315で確認できる。
